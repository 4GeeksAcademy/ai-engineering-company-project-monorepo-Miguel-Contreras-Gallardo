# TrackFlow · Sitio web corporativo

Presencia web pública de TrackFlow. Sitio informativo construido con HTML, CSS y JavaScript vanilla — sin compilación, sin dependencias de framework.

## Contenido

- **Hero** — Propuesta de valor y datos clave (130+ empleados, 9M€, 8 transportistas)
- **La empresa** — Historia, fundación y métricas
- **Servicios** — Almacenamiento, preparación, envío, logística inversa
- **Presencia global** — Los Ángeles y Zaragoza
- **Equipo** — Directivos y responsables de área (datos extraídos de `CONTEXT.md`)
- **Contacto** — Formulario de contacto

## Ejecución local

```bash
python -m http.server 5173
```

Abrir `http://localhost:5173` en el navegador.

## Stack

- HTML semántico
- CSS con variables de diseño y media queries responsive
- JavaScript vanilla (manejo de menú móvil, envío de formulario)
- Lucide icons vía CDN
