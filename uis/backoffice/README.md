# TrackFlow backoffice

Panel operativo sin proceso de compilación para administrar artículos, lotes y movimientos, consultar stock derivado y ver señales de reorden.

## Ejecución local

Con la API disponible en `http://localhost:8000`:

```bash
python -m http.server 5173
```

Ejecutar el comando desde esta carpeta y abrir `http://localhost:5173`.
